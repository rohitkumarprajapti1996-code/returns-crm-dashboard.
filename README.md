# Returns CRM Dashboard

This project is ready for GitHub Pages. The published dashboard is `docs/index.html`.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `returns-crm-dashboard`.
2. Upload this project folder to the repository, including the `docs` folder.
3. In the repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/docs**, then save.
6. GitHub will show the website URL after publishing completes.

The dashboard processes the K8 and AAJ RMS CSV files in the visitor's browser. Uploaded CSV data is not committed to the repository or stored by GitHub Pages.
